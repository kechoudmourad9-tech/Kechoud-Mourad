# Goûts du projet
- Style : système « explainer reel » du skill. Papier `#F2EFE8` avec grain, encre `#141414`, une seule couleur d'accent rouge `#E8322B` (bleu `#2F5BFF` pour B et le chapitre des ensembles).
- Texte : Alexandria pour les sous-titres, Instrument Serif italique rouge pour les mots-clés, Anton pour les tampons, JetBrains Mono pour le cadre fixe.
- Sous-titres : système A (éditorial en haut, mot par mot), le même sur toute la vidéo.
- Transitions : trame de points (halftone) entre les chapitres.
- Son : voix off à −14 LUFS, pas de musique, bruitages courts (pop, whoosh, tampon, tics de frappe, notification).
- Fin : commentaire « MATHS », puis un message reçu (à adapter si l'automatisation commentaire → message n'existe pas).
